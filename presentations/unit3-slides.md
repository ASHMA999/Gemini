# The Browser as AI OS

> **Microsoft's vision: the browser becomes your operating system for AI**

- **Edge** is no longer just a browser -- it is an AI-powered workspace
- Copilot is embedded at the OS level (Windows), browser level (Edge), and app level (M365)
- The browser becomes the **universal interface** for AI assistance

**What this means for APC:**

| Traditional Workflow | AI-Augmented Workflow |
|---------------------|----------------------|
| Open app, do work, save file | Open app, **describe intent**, review & refine output |
| Search intranet for policy | **Ask Copilot** to find and summarize the policy |
| Manually compile reports | Copilot **drafts report** from your data sources |
| Schedule meetings via back-and-forth email | Copilot **finds optimal time** and sends invites |

# Copilot in Word

> **From blank page to polished document in minutes**

**Core features:**
- **Draft** entire documents from a prompt
- **Rewrite** selected text with tone/length adjustments
- **Summarize** long documents into key points
- **Transform** content -- e.g., turn notes into a formal report

**Effective prompts for Word:**

```
Draft a safety procedure document for potash loading operations.
Include: scope, responsibilities, step-by-step procedure,
PPE requirements, and emergency contacts.
Format with numbered sections and a revision history table.
```

> **From outline to presentation deck in seconds**

**Core features:**
- **Create presentation** from a prompt or Word document
- **Add slides** on specific topics
- **Redesign** slides for better visual layout
- **Summarize** a long deck into key slides

**Best practices for APC presentations:**

1. Start with a **detailed prompt** including audience and purpose
2. Use **"Create from file"** with an existing Word report for consistency
3. Always **review and refine** -- Copilot provides the draft, you provide the judgment
4. Add **APC branding** manually after Copilot generates the structure

# Admin Policies & Governance

> **Enterprise AI requires enterprise governance**

**Key admin controls for Copilot 365:**

| Policy Area | Control Options |
|------------|----------------|
| **Data access** | Copilot respects existing M365 permissions -- review and tighten as needed |
| **User licensing** | Assign Copilot licenses by role, department, or pilot group |
| **Usage reporting** | Monitor adoption rates, query volumes, and feature usage |
| **Sensitivity labels** | Copilot honors Information Protection labels -- classified content stays protected |
| **Plugin management** | Enable/disable third-party and custom plugins per policy |
| **Audit logging** | All Copilot interactions logged for compliance review |

**APC recommendations:**
1. Start with a **pilot group** before full rollout
2. **Audit M365 permissions** -- Copilot surfaces content users already have access to
3. Train users on **what not to share** with AI tools
4. Establish a **Responsible AI policy** aligned with APC values
