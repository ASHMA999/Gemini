These files contain **fictional data** created for training purposes. No real company data is included. All names, values, and incidents are simulated.

## Usage Instructions

1. **Download** the CSV file you need for the exercise
2. **Upload** it to the AI tool specified in the exercise (ChatGPT, Claude, etc.)
3. **Follow** the exercise prompts in the worksheet
4. **Never** replace these with real company data in a free AI tool

---

## Data Privacy Notice

These are synthetic datasets designed to mimic real-world patterns without containing any actual company information. They are safe to upload to any AI tool for training purposes.
