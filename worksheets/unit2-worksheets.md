## Framework Quick-Reference Card

Cut out or bookmark this section for use during all exercises.

### CO-STAR Framework

| Letter | Element | Description | Example |
|--------|---------|-------------|---------|
| **C** | Context | Background information and situation | "We are a mid-size logistics company..." |
| **O** | Objective | What you want the AI to do | "Create a weekly status report..." |
| **S** | Style | Writing style or voice to use | "Professional, concise, executive tone" |
| **T** | Tone | Emotional quality of the response | "Confident but not aggressive" |
| **A** | Audience | Who will read/use the output | "C-suite executives, non-technical" |
| **R** | Response Format | Desired structure/format | "Bullet points, max 1 page, with headers" |

### Other Key Frameworks

| Framework | Structure | Best For |
|-----------|-----------|----------|
| **RTF** | Role, Task, Format | Quick everyday tasks |
| **RISEN** | Role, Instructions, Steps, End goal, Narrowing | Complex multi-step tasks |
| **Chain-of-Thought** | "Think step by step..." | Reasoning and analysis |
| **Few-Shot** | Example 1, Example 2 → New task | Pattern-matching and classification |
| **Tree-of-Thought** | Explore multiple reasoning paths | Decision-making with trade-offs |
| **APC** | Actor, Purpose, Context | Industrial/operational tasks |
