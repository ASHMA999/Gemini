## Worksheet 8-E: Presentation Outline Template (5-Minute Structure)

**Instructions:** Fill in each section. Practice delivering it within the time limits shown.

| Section | Time | Content |

| What action should be taken? What is the potential benefit? | | |

| **5. Lessons Learned** | 4:00 - 4:45 | |
| What did you learn about working with AI? What would you do differently? | | |
| | | |
| | | |
| **6. Q&A Buffer** | 4:45 - 5:00 | |
| Invite questions. | | |

### Presentation Checklist

- [ ] Slides are ready (max 5-7 slides)
- [ ] Key visual / chart is clear and readable from the back of the room
- [ ] I can explain my project without reading from notes
- [ ] I have practiced and timed my delivery: _________ minutes
- [ ] I have a backup plan if the live demo fails

> **Key Takeaway:** Five minutes is enough to make an impact — if you are focused. Lead with the problem, show one powerful insight, and end with a clear call to action.
