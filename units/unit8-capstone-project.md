# Unit 8: Capstone Project & Assessment

## Integrating All Skills into Real-World Practice

| Detail | Description |
|--------|-------------|
| **Duration** | 3 hours |
| **Delivery** | Project-based with peer review |
| **Tools Required** | All tools from previous units |
| **Objective** | Apply all learned skills to solve a real challenge from the trainee's own work environment |

---

## 8.1 The Capstone Challenge

Each trainee (or team) selects a real problem from their department and solves it using the full AI toolkit.

### Scenario: Regulatory Inspection Preparation

Arab Potash Company is preparing for an inspection visit from the Energy & Minerals Regulatory Commission.

| Department | Required Deliverables | Suggested AI Tools |
|-----------|----------------------|-------------------|
| HR | Training records, safety statistics, certification logs | ChatGPT (document generation), Claude (analysis) |
| Production | Production reports, emissions logs, emergency plan | Code Interpreter (data analysis), Copilot (report drafting) |
| Maintenance | Maintenance logs, equipment inspection reports, schedule | Claude (detailed reports), Gemini (document processing) |

---

## 8.2 Project Requirements

1. **Problem Statement:** Clearly define the real-world problem using CO-STAR framework
2. **AI Tool Selection:** Justify which tools you chose and why (minimum 3 different tools)
3. **Prompt Engineering:** Show your prompt evolution (first draft to final optimized version)
4. **Data Analysis:** If applicable, include at least one data visualization or analytical output
5. **Security Check:** Demonstrate that all data handling followed enterprise security guidelines
6. **Results Presentation:** 5-minute presentation to the class with Q&A

---

## 8.3 Evaluation Criteria

| Criterion | Weight | Description |
|----------|--------|-------------|
| Prompt Quality | 30% | Proper use of frameworks (CO-STAR, RACE, etc.), clarity, and precision |
| Tool Mastery | 25% | Effective use of multiple AI tools and knowing when to use which |
| Practical Value | 25% | Does the solution actually solve a real problem? Is it immediately usable? |
| Security Awareness | 10% | Demonstrated understanding of data privacy and enterprise AI risks |
| Presentation | 10% | Clear communication of process and results |

### Capstone Project Work Session (90 minutes)

Teams of 2-3 people work on their chosen problem. The trainer circulates to coach, suggest tools, and help optimize prompts. At the end, each team presents their solution, and peer review scores are collected.
