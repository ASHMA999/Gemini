# Unit 8: Capstone Evaluation Rubric

**Program:** AI Training Program -- Capstone Project
**Total Points:** 100 (weighted)
**Passing Score:** 70/100

---

## Overview

This rubric is used to evaluate the Unit 8 Capstone Project, in which participants demonstrate mastery of AI tools and prompt engineering by solving a real workplace problem. Evaluators should score each criterion independently using the detailed level descriptors below. The final score is calculated using the weighted formula at the end of this document.

---

## Criterion 1: Prompt Quality (30%)

| Level | Score | Observable Behaviors |
|-------|-------|----------------------|
| **Level 1 -- Inadequate** | 1 | Prompts are vague, unstructured, and use no recognizable framework. No role assignment, no constraints, no output formatting. Prompts resemble casual conversation (e.g., "Tell me about maintenance"). |
| **Level 2 -- Developing** | 2 | Prompts show some structure but are inconsistent. May include a role OR context but not both. Constraints are absent or superficial. Output is partially useful but requires significant rework. |
| **Level 3 -- Competent** | 3 | Prompts use a recognizable framework (e.g., CO-STAR, APC) with most elements present. Role, context, and output format are defined. At least one constraint is included. Output is usable with minor edits. |
| **Level 4 -- Proficient** | 4 | Prompts are well-structured using an appropriate framework with all elements clearly defined. Multiple constraints are applied (length, format, exclusions, audience). Evidence of iteration -- the participant refined prompts based on initial outputs. |
| **Level 5 -- Exemplary** | 5 | Prompts demonstrate mastery of CO-STAR or equivalent framework with expertly crafted constraints, audience calibration, and iterative refinement. Prompts are production-ready and could serve as organizational templates. Evidence of advanced techniques (Few-Shot, Chain-of-Thought, Multi-Role) where appropriate. |

---

## Criterion 2: Tool Mastery (25%)

| Level | Score | Observable Behaviors |
|-------|-------|----------------------|
| **Level 1 -- Inadequate** | 1 | Used only one AI tool for the entire project. No justification for tool selection. Tool was used in the most basic way (e.g., simple chat only). |
| **Level 2 -- Developing** | 2 | Used two AI tools but selection was arbitrary or poorly justified. Tools were used at a surface level without leveraging their unique capabilities. |
| **Level 3 -- Competent** | 3 | Used two to three AI tools with reasonable justification for selection. Demonstrated understanding of each tool's strengths (e.g., Copilot for M365 integration, NotebookLM for source-grounded research). |
| **Level 4 -- Proficient** | 4 | Used three to four AI tools with clear, logical justification for each selection. Demonstrated strong command of each tool's unique features and appropriate use cases. Tools were combined in a complementary workflow. |
| **Level 5 -- Exemplary** | 5 | Used four or more AI tools with perfect selection logic. Each tool was chosen for its specific strength and used to its full potential. The participant articulated a clear rationale for the tool ecosystem, demonstrated fluency across platforms, and showed awareness of each tool's limitations. |

---

## Criterion 3: Practical Value (25%)

| Level | Score | Observable Behaviors |
|-------|-------|----------------------|
| **Level 1 -- Inadequate** | 1 | Project is entirely theoretical with no connection to a real workplace problem. Outputs are generic and could not be applied in any practical setting. |
| **Level 2 -- Developing** | 2 | Project addresses a real-world topic but the solution is too generic or incomplete to be actionable. Outputs would require major rework to be useful in a workplace. |
| **Level 3 -- Competent** | 3 | Project addresses a genuine workplace problem with a workable solution. Outputs are mostly practical and could be used with some adaptation. The time-saving or quality-improvement benefit is identifiable. |
| **Level 4 -- Proficient** | 4 | Project solves a clearly defined workplace problem with a well-developed solution. Outputs are practical, well-formatted, and could be used with minimal adaptation. Clear ROI or efficiency gain is demonstrated. |
| **Level 5 -- Exemplary** | 5 | Project delivers an immediately deployable solution to a significant workplace problem. Outputs are polished, professional, and ready for use. The participant quantified the impact (time saved, cost reduced, quality improved) and the solution could be replicated by colleagues. |

---

## Criterion 4: Security Awareness (10%)

| Level | Score | Observable Behaviors |
|-------|-------|----------------------|
| **Level 1 -- Inadequate** | 1 | No consideration of data privacy or security. Uploaded sensitive data to public AI tools without safeguards. No mention of confidentiality. |
| **Level 2 -- Developing** | 2 | Mentioned data privacy in passing but did not demonstrate practical safeguards. May have used anonymized data but without explaining why. |
| **Level 3 -- Competent** | 3 | Demonstrated awareness of data classification. Used anonymized or synthetic data where appropriate. Mentioned which tools have enterprise data protection and which do not. |
| **Level 4 -- Proficient** | 4 | Applied a clear data security protocol throughout the project. Chose tools based partly on their security posture (e.g., Copilot EDP vs. public ChatGPT). Explained data handling decisions for each step. |
| **Level 5 -- Exemplary** | 5 | Full security protocol demonstrated throughout. Classified all data before use. Selected tools with explicit security justification. Anonymized sensitive data. Documented what should never be uploaded. Could serve as a model for organizational AI governance. |

---

## Criterion 5: Presentation (10%)

| Level | Score | Observable Behaviors |
|-------|-------|----------------------|
| **Level 1 -- Inadequate** | 1 | Presentation is unclear, disorganized, or missing key sections. Difficult to follow. No logical structure. Exceeded time limit significantly or was far too brief. |
| **Level 2 -- Developing** | 2 | Presentation has some structure but is uneven. Key points are present but poorly explained. Visual aids are absent or unhelpful. Delivery is hesitant. |
| **Level 3 -- Competent** | 3 | Presentation is organized with a clear beginning, middle, and end. Key points are communicated adequately. Visual aids are present and relevant. Delivered within time limit. |
| **Level 4 -- Proficient** | 4 | Presentation is well-organized, clear, and engaging. Visual aids enhance understanding. The participant demonstrated confidence and answered questions competently. Good time management. |
| **Level 5 -- Exemplary** | 5 | Presentation is professional, concise, and compelling. Narrative is clear and persuasive. Visual aids are polished and effective. The participant demonstrated deep understanding, handled questions with expertise, and stayed within time limits. Could be presented to senior leadership as-is. |

## Scoring Worksheet

### Individual Scores

| Criterion | Weight | Raw Score (1-5) | Weighted Score |
|-----------|--------|-----------------|----------------|
| Prompt Quality | 30% | ___ | Raw x 6 = ___ |
| Tool Mastery | 25% | ___ | Raw x 5 = ___ |
| Practical Value | 25% | ___ | Raw x 5 = ___ |
| Security Awareness | 10% | ___ | Raw x 2 = ___ |
| Presentation | 10% | ___ | Raw x 2 = ___ |
| **TOTAL** | **100%** | | **___ / 100** |

### Weighted Calculation Formula

```
Final Score = (Prompt Quality x 6) + (Tool Mastery x 5) + (Practical Value x 5) + (Security Awareness x 2) + (Presentation x 2)
```

**Example:** A participant scoring 4, 3, 4, 3, 4 across the five criteria:
```
(4 x 6) + (3 x 5) + (4 x 5) + (3 x 2) + (4 x 2) = 24 + 15 + 20 + 6 + 8 = 73/100 -- PASS
```

### Score Interpretation

| Total Score | Result | Description |
|-------------|--------|-------------|
| 90-100 | Distinction | Exceptional performance across all criteria |
| 80-89 | Merit | Strong performance with minor gaps |
| 70-79 | Pass | Meets all minimum competency requirements |
| 60-69 | Conditional Pass | Requires revision and resubmission of weak areas |
| Below 60 | Not Yet Competent | Must redo capstone with additional support |
